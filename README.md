

# 📱 Contact Mobile Application

### Flutter + PHP + MySQL

A full-stack **mobile contact management application** developed using **Flutter** for the frontend and **PHP + MySQL** for the backend.

This application allows users to securely manage their contacts and perform direct phone calls by selecting a SIM card.

---

## 🚀 Project Overview

The Contact Mobile Application provides a simple and efficient way to:

* 🔐 Authenticate users (Login system)
* ➕ Add new contacts
* ✏️ Edit existing contacts
* ❌ Delete contacts
* 📞 Make phone calls
* 📱 Choose SIM card before calling

The system combines mobile UI design with a backend API and database management.

The app includes:

* Direct call functionality

This improves flexibility for users managing multiple numbers.

---

## 📡 System Architecture

1. User interacts with Flutter mobile UI.
2. Flutter sends HTTP requests to PHP backend.
3. PHP processes requests and communicates with MySQL database.
4. JSON responses are returned to the mobile app.

This creates a clean client-server architecture.

---

## 📦 Installation & Setup

### 🔹 Backend Setup

1. Install a local server (e.g., XAMPP)
2. Import the database using:

   * phpMyAdmin
3. Configure database connection in PHP files.

---

### 🔹 Frontend Setup

```bash
git clone https://github.com/your-username/contact_mobile_application.git
cd contact_mobile_application
flutter pub get
flutter run
```

Make sure your backend API URL is correctly configured in the Flutter project.
